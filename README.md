## 📖 Project Overview

**Africa** is an iOS application built with **Swift** and **SwiftUI**. It is a hands-on portfolio project that demonstrates how to build a clean, data-driven native iOS interface using Apple's modern declarative UI framework.

The project focuses on core skills every iOS developer needs: structuring a SwiftUI app, loading and decoding **JSON** data with **Codable**, presenting location data with **MapKit**, and building reusable SwiftUI views.

## 🚀 Getting Started

### Prerequisites

- A Mac running a recent version of macOS
- [Xcode](https://developer.apple.com/xcode/) (latest stable version recommended)
- An iOS Simulator or a physical iPhone
- Git

---

## ⚙️ Installation and Running Instructions

**1. Clone the repository**

```bash
git clone https://github.com/hossam556k/Africa.git
```

**2. Navigate into the project folder**

```bash
cd Africa
```

**3. Open the project in Xcode**

```bash
open Africa.xcodeproj
```

**4. Run the app**

1. Select an iPhone simulator (or your connected device) from the device menu in Xcode.
2. Press **Cmd + R** or click the **Run** ▶️ button.

> 💡 If Xcode reports a signing issue when running on a physical device, select your own team under **Signing & Capabilities** in the project settings.
